## 1.2 Data in today's world

Challenges

1. Variety of data: formats, (semi / un) structured
2. Rate or Velocity: streaming, incoming volume
3. Integrating data: multiple data streams
4. Infrastructure: cost for storing data
5. Security: sensitive information
6. Governance: the right procedures in place

데이터 관점에서 **거버넌스(Governance)**는 쉽게 말하면 **“데이터를 조직 안에서 어떻게 관리하고, 누가 책임지고, 어떤 규칙으로 사용할지를 정하는 체계”**입니다.

특히 **Data Governance(데이터 거버넌스)**는 단순히 데이터를 저장하거나 관리하는 기술이 아니라, 데이터에 대한 **정책·역할·책임·표준·통제**를 정하는 것입니다.

예를 들어 회사에 고객 데이터가 있다고 하면, 데이터 거버넌스는 다음과 같은 질문에 답합니다.

- **Ownership:** 이 데이터의 책임자는 누구인가?
- **Access:** 누가 이 데이터를 볼 수 있는가?
- **Quality:** 데이터가 정확한지 누가 관리하는가?
- **Definition:** “고객”, “매출”, “활성 사용자” 같은 용어를 회사 전체에서 어떻게 정의하는가?
- **Security & Privacy:** 개인정보나 민감정보를 어떻게 보호하는가?
- **Lifecycle:** 데이터를 얼마나 오래 보관하고 언제 삭제하는가?
- **Compliance:** GDPR 같은 법규를 어떻게 준수하는가?

Different Roles

1. Data Engineer: maintaining infrastructures, get raw data from incoming sources
2. Data Analyst: reports, insights, visualizations
3. Data Scientist: stats, math, computational techs to extract insights from data
4. ML Engineers: build ML models to solve business problems.
